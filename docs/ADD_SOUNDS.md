# إضافة أصوات الأذان

ضع الملفات (mp3) داخل `assets/audio/` بهذه الأسماء، وستظهر تلقائياً في قائمة اختيار الصوت:

| الملف | الاستخدام |
|---|---|
| `adhan_takbeer.mp3` | **الافتراضي** – تكبير "الله أكبر الله أكبر" (~5 ثوانٍ) |
| `adhan_mecca.mp3` | أذان مكة |
| `adhan_madina.mp3` | أذان المدينة |
| `adhan_aqsa.mp3` | أذان الأقصى |
| `adhan_egypt.mp3` | أذان مصر |
| `adhan_sham.mp3` | أذان الشام |
| `adhan_fajr.mp3` | أذان الفجر |

أي ملف باسم `adhan_*.mp3` يُضاف أيضاً تلقائياً. ملف `adhan_takbeer.mp3` الحالي نسخة مؤقتة قصيرة؛ استبدله بالتسجيل الحقيقي بنفس الاسم.
